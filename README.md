# amaya-demo-inapp

Демо-копия файлов локалей InApp для проверки кнопки «В проекты» сервиса локализации Amaya Hub.
Это не рабочий репозиторий: здесь только `src/locales/{lang}.json`, кода проекта нет.

Сервис открывает PR из ветки `amaya-hub/<набор>` с утверждёнными текстами. В `main` он не пишет —
тексты попадают сюда, только когда PR смержат.
